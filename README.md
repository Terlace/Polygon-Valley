# Polygon Valley

Polygon Valley was an Unreal Engine project I had to do for my Video Game 1 class.

**TASK:** We had to make a 3D platformer in Unreal Engine 5.6 using the provided asset template inspired by the game Sokoban.

**Submission Date:** September 23rd, 2026

## Description

The player must pick up boxes in order to place them on their respective platform (matching color) in order to access higher areas.

Placing boxes on their matching platform makes them float midair, allowing the player to jump on top of them.

Some platforms appear thicker than others. They must be jumped on from another object.

The goal is to place every single box on their matching platform to finish the game.

## Controls

**Moving Around:** WASD

**Jumping:** Space

**Picking up / placing boxes:** E

## Reference

The project had to be inspired by Sokoban, an old puzzle game where the player moves boxes to place them on their respective slot.
